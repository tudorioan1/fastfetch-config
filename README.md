# fastfetch-config
This repository contains my custom Fastfetch configuration, designed to personalize and enhance the terminal experience. It provides a tailored system information layout with a clean, visually appealing setup for Fastfetch.
<img width="1196" height="756" alt="image" src="https://github.com/user-attachments/assets/6a89bd7f-209d-46cb-a59c-caffa5f33917" />


<p> <strong> Install Dependencies </strong> </p>

Before using this configuration, ensure you have Fastfetch installed.

<details>
  <summary>Arch Linux</summary>

```bash
sudo pacman -Sy fastfetch
```
</details>

<details> <summary>Fedora</summary>

```bash
sudo dnf install fastfetch
```
</details>

<details> <summary>Debian/Ubuntu-based</summary>

```bash
sudo apt install fastfetch
```
</details>

<br>

<p> <strong> Installation </strong> </p>

```shell
git clone https://github.com/tudorioan1/fastfetch-config.git
mkdir -p ~/.config/fastfetch
cp -r fastfetch-config/* ~/.config/fastfetch/
```

<p> <strong> Verify Installation </strong> </p>

To ensure everything is set up correctly, run Fastfetch in your terminal

```shell
fastfetch
```
